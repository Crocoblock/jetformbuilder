---
name: wordpress-bugfix
description: Trace and fix WordPress plugin defects with a small, evidence-based change.
---

Reproduce or precisely trace the reported behaviour before editing. Find an analogous working pattern in this repository and compare hooks, data flow, validation, capabilities, persistence, and output. Identify the root cause and implement the smallest compatible fix. Preserve public APIs and WordPress conventions. Run the exact relevant checks that are available; report every command and its real result. Never claim an unexecuted check passed.
